# Fundamentals of Utilizing Data Sources

Course material for TU Wien, Building Sciences and Environment. Five sessions, each a Jupyter notebook with
the lecture text, a small gap to fill, tests and a homework at the end.

1. Files: where data lives
2. The web: asking a machine for data
3. Sensors: data as JSON
4. Databases: keeping data in order
5. Putting it together: a digital twin of the classroom

Get it onto the TU Wien JupyterHub with *Git → Clone a Repository* and this repository's URL (tick
"Download the repository"). Open the notebooks in `notebooks/`; the solution versions end in `_solution`.

Apps (work on a phone, also offline once loaded):

- Flashcards with the terms of every session: [webapps/flashcards](https://gabriel-wurzer.github.io/data/webapps/flashcards/)
- Occupancy sensor, counts people at a door with your phone's camera:
  [webapps/occupancy-sensor](https://gabriel-wurzer.github.io/data/webapps/occupancy-sensor/)

Data from the City of Vienna (CC BY 4.0) and the Sensoto open sensor network.
